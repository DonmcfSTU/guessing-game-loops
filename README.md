## What the program does
`guessingGame.py` asks for my name and Student ID and greets me. Then it has me guess a secret number between 1 and 10 (the number is 5). An if/elif/else statement tells me if each guess is too high, too low, or correct, and the program counts how many tries I took. After that, a `while` loop and a `for` loop each add 1 to the correct guess five times and print the results.

## How to run
Open `guessingGame.py` in Python IDLE and choose **Run > Run Module**.
